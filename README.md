# ⚡ Happ Proxy Auto-Updater (No-VPS & 100% Free)

Полностью автономный, бесплатный и самообновляющийся генератор подписок для клиента **Happ Proxy** (iOS, Android, macOS, Windows).

Система собирает свежие конфигурации узлов (**VLESS Reality**, **Trojan**, **Shadowsocks**, **Hysteria2**), фильтрует и дедуплицирует их, обновляет секретный **GitHub Gist** и регистрирует зашифрованную ссылку `happ://crypt5/...` через официальный шлюз Happ Crypto.

---

## 🏗️ Архитектура системы

```
┌────────────────────────────────┐
│   Публичные агрегаторы узлов   │ (GitHub Repos / Мирроры)
└───────────────┬────────────────┘
                │
                ▼
┌────────────────────────────────┐
│ GitHub Actions (Cron каждые 4ч)│
│  - main.py (Парсинг, очистка,  │
│    ранжирование и Base64)      │
└───────────────┬────────────────┘
                │
                ▼
┌────────────────────────────────┐
│      GitHub Gist (Secret)      │
│  https://gist.githubuser...    │ ◄── Постоянный RAW URL (HEAD)
│  (subscription.txt)            │
└───────────────┬────────────────┘
                │
                ▼
┌────────────────────────────────┐
│      API crypto.happ.su        │ (Шифрование URL в happ://crypt5/...)
└───────────────┬────────────────┘
                │
                ▼
┌────────────────────────────────┐
│      Клиент Happ Proxy         │
│  - Добавляется 1 раз в жизни   │
│  - Обновляет узлы по расписанию│
└────────────────────────────────┘
```

> [!NOTE]
> **Почему это не требует повторного ввода ссылки?**  
> GitHub Gist предоставляет постоянный RAW-URL без хэша коммита (`https://gist.githubusercontent.com/<username>/<gist_id>/raw/subscription.txt`). Клиент Happ расшифровывает ссылку `happ://crypt5/...` один раз при добавлении и сохраняет за ней этот неизменный URL. Каждый раз, когда приложение Happ обновляет подписку, оно обращается по этому адресу и скачивает новейший список серверов.

## 🚀 Пошаговая инструкция по настройке

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Задайте имя репозитория, например: `happ-subscription-updater`.
3. Тип репозитория: **Private** (или **Public** по вашему желанию).
4. Загрузите файлы этого проекта (`main.py`, `requirements.txt`, `.github/workflows/update.yml`, `README.md`) в репозиторий.

---

### Шаг 2. Создайте GitHub Personal Access Token (PAT)
Скрипту нужен токен для создания и автоматического обновления вашего Gist:
1. Откройте страницу создания токенов: [GitHub Personal Access Tokens (Tokens classic)](https://github.com/settings/tokens/new).
2. В поле **Note** введите: `Happ Gist Updater`.
3. В поле **Expiration** выберите `No expiration` (или нужный вам срок).
4. В блоке **Select scopes** отметьте галочку:
   - ✅ **`gist`** *(Create gists)*.
5. Прокрутите вниз и нажмите зеленую кнопку **Generate token**.
6. **Скопируйте полученный токен** (он начинается с `ghp_...`).

---

### Шаг 3. Добавьте токен в Secrets репозитория
1. В вашем репозитории перейдите во вкладку **Settings** (Настройки).
2. В левом меню выберите **Secrets and variables** ➔ **Actions**.
3. Нажмите кнопку **New repository secret**.
4. Создайте секрет:
   - **Name**: `GIST_TOKEN`
   - **Secret**: вставьте скопированный токен `ghp_...`
5. Нажмите **Add secret**.

*(Опционально)* Если у вас уже есть существующий Gist и вы хотите использовать именно его, создайте второй секрет `GIST_ID` со значением идентификатора Gist. Если этот секрет не указан, **скрипт создаст Gist автоматически при первом запуске**!

---

### Шаг 4. Первый запуск и получение ссылки `happ://`
1. В репозитории откройте вкладку **Actions**.
2. В левой колонке нажмите на воркфлоу **Update Happ Proxy Subscription**.
3. Справа нажмите кнопку **Run workflow** ➔ **Run workflow**.
4. Дождитесь завершения выполнения (около 10–20 секунд, появится зеленый чекбокс ✅).
5. Нажмите на завершившийся запуск.
6. В разделе **Summary** (Сводка) вы увидите готовый отчет с вашей персональной ссылкой:
   ```text
   happ://crypt5/fzvd...
   ```
   Также ссылка будет сохранена в файле `happ_link.txt` в вашем репозитории.

---

### Шаг 5. Добавление ссылки в Happ Proxy
1. Скопируйте ссылку `happ://crypt5/...`.
2. Откройте приложение **Happ Proxy** на вашем устройстве.
3. Перейдите в раздел подписок и нажмите **Добавить подписку** (или иконку **+**).
4. Вставьте ссылку `happ://crypt5/...`.
5. Приложение расшифрует адрес и загрузит рабочие узлы.
6. В настройках подписки включите **Автообновление** (Auto-update) с интервалом 4–12 часов.

**Готово!** Теперь GitHub Actions каждые 4 часа обновляет узлы в Gist, а клиент Happ самостоятельно подтягивает свежие рабочие серверы.

## ⚙️ Локальный запуск (для тестирования)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Тестовый прогон без токена (сохранит результат в subscription.txt)
python main.py

# Запуск с обновлением Gist
export GIST_TOKEN="ghp_ваш_токен"
# (на Windows PowerShell: $env:GIST_TOKEN="ghp_ваш_токен")
python main.py
```
